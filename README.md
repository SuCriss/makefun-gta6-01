Neon Hustle is a self-contained top-down open-world crime game. Steal cars, weave through traffic, outrun a five-star police chase, grab cash drops and work through story contracts in a neon-soaked city grid. Everything runs offline from static HTML, CSS and ES modules.

## Run it

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Open `out/game/index.html` in a browser. Deterministic preview scenes are available with `?shot=start`, `?shot=play` and `?shot=end&seed=1`.
