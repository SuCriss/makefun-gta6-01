Neon Hustle is a self-contained, browser-only top-down open-world crime game. Drive stolen cars through a neon city grid, take cash pickups, outrun the police, and work through three story missions. Everything runs offline from static HTML, CSS, and ES modules.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Open `out/game/index.html` in a browser. Add `?shot=start`, `?shot=play`, or `?shot=end&seed=1` for deterministic composed scenes.
